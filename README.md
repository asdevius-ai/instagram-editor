# Макет Instagram-профілю

Редактор-чернетка Instagram-профілю для телефону: аватар, біо, актуальне, сітка дописів 3:4, каруселі,
перетягування для зміни порядку. Потім усе переноситься в справжній Instagram.

- Вигляд максимально наближений до Instagram: шапка з галочкою, кільце сторіз, хештеги й згадки синім,
  іконка ланцюжка біля посилання, блок «Професійна панель», закріплені дописи (до 3), перегляд допису як у стрічці
  (лайки, геотег, «ще», дата, каруселі), «Чистий вигляд» для скріншотів без кнопок редактора.
- Відео й **Reels** (вкладка Reels + повноекранний перегляд зі свайпом і звуком), **сторіз і актуальне** зі справжнім переглядом
  (смужки прогресу, тап вліво/вправо, утримання = пауза, текст на сторіз), вкладка **«Тегнуті»**, рядок
  «Вподобали X та ще N», **кілька акаунтів** з перемиканням (тап на ім'я вгорі).
- Працює як додаток на айфоні (PWA) і **офлайн**.
- Усе (фото й тексти) зберігається **лише в телефоні** (IndexedDB), на сервер нічого не відправляється.
- Один файл `index.html` без бібліотек і збірки.

## Як поставити на айфон

Safari не вміє ставити додатки з локального файлу, тому сторінку треба один раз виставити за посиланням.
Це безкоштовно й без сервера.

**GitHub Pages**
1. Влий ці файли в гілку `main` репозиторію.
2. Репозиторій → *Settings* → *Pages* → *Source: Deploy from a branch* → `main` / `/ (root)` → *Save*.
   (Для приватного репозиторію Pages потребує платного плану. Тоді зроби репозиторій публічним або використай варіант нижче.)
3. Через хвилину буде посилання `https://<користувач>.github.io/instagram-editor/`.

**Або Netlify Drop**: відкрий <https://app.netlify.com/drop> з комп’ютера, перетягни туди папку з файлами — отримаєш посилання.

**На айфоні:** відкрий посилання в **Safari** → кнопка «Поділитись» → **«На початковий екран»**.
Далі запускай з іконки: вона відкривається на весь екран, без інтернету, дані не зникають.
Не відкривай і не працюй у вкладці Safari, а тільки з іконки: Safari може чистити дані сайтів, а встановлений додаток — ні.

## Як перенести в Instagram

Вкладка **«В Instagram»**:
1. Профіль: копіюй ім’я, біо, посилання, збережи фото профілю.
2. Дописи йдуть у порядку публікації: від найстарішого (внизу сітки) до найновішого. Для кожного: «Підпис» копіює текст,
   «Фото» відкриває меню «Поділитись» → Instagram або «Зберегти зображення».
3. Позначай «Опубліковано», щоб не загубитись.

Instagram не дозволяє стороннім сайтам постити за користувача, тому перенесення ручне, але готове до кількох тапів.

## Резервна копія

Вкладка «В Instagram» → «Зберегти копію» створює один `.json` файл з усіма акаунтами та фото. Збережи його у «Файли»/iCloud.
«Відновити з копії» повертає макет, наприклад на новому телефоні.
**Самі відео в копію не входять** (вони завеликі для одного файлу): лишаються обкладинки. Оригінали відео бережи в галереї.
